# Retail Sales Analysis Project

## Summary

This project analyzes retail store sales data using Python and Pandas.
The goal is to clean the dataset, identify sales trends, and create
visualizations that provide insights into store and product performance.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Power BI

## Project Features 

- Data cleaning and preprocessing
- Handling missing values
- Data validation
- Sales analysis
- Product performance analysis
- Data visualization
- Automated reporting

## Dataset

The project uses retail store sales data containing information such as:

- Transaction Date
- Store
- Item
- Category
- Quantity
- Price Per Unit
- Total Spent

## How to run

### 1. Clone the repo

git clone https://github.com/Ike-Ani//retail-sales-analysis.git

### 2. Navigate to the project

cd retail-sales-analysis

### 3. Install dependencies

pip install -r requirements.txt

### 4. Run the Python script

python main.py
